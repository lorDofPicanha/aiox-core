## Frameworks & Methods
- **ML System Design Framework**: Requirements -> Data -> Features -> Model -> Serving -> Monitoring
- **Four Layers of ML Infra**: Data platform, feature platform, model platform, serving platform
- **Feature Store Pattern**: Centralized feature computation, storage, and serving
- **Data Distribution Shift Detection**: Covariate shift, label shift, concept drift monitoring
- **Online vs Offline Feature Engineering**: Real-time transformations vs batch-computed features
- **Model Compression**: Quantization, pruning, distillation for edge/mobile deployment
- **Continual Learning**: Models that adapt to new data without full retraining

## Key Principles
1. **"ML in production is 90% engineering, 10% ML"**
2. Data quality monitoring is as important as model quality monitoring
3. Feature engineering is the highest-leverage ML activity
4. Simple models with great features beat complex models with poor features
5. Plan for model degradation from day one
6. Edge cases in production will break your prettiest notebook model
7. ML systems should be evaluated end-to-end, not component by component
