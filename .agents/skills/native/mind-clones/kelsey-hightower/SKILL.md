## Key Principles
1. **"Kubernetes is not the goal — shipping software reliably is"**
2. Simplicity over complexity — don't use K8s if you don't need it
3. Automate operations, not just deployment
4. Platform teams should be product teams serving developers
5. Observability is a prerequisite for operating distributed systems
6. Immutable infrastructure reduces configuration drift
7. The best infrastructure is the one developers don't have to think about
