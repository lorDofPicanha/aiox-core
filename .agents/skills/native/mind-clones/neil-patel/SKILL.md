# Neil Patel — Expert Skills

## Core Expertise
- Search Engine Optimization (SEO) — technical, on-page, off-page
- Content marketing strategy and distribution
- Conversion rate optimization (CRO) and funnel analysis
- Growth hacking and rapid experimentation
- Digital marketing analytics and attribution

## Frameworks & Methods
- **SEO Framework**: Technical audit -> Keyword research -> Content creation -> Link building -> Monitoring
- **Ubersuggest Method**: Long-tail keyword discovery and competitive gap analysis
- **Content Upgrade Strategy**: Lead magnets within content for conversion
- **Skyscraper Technique**: Find top content, make something 10x better, promote it
- **CRO Process**: Data -> Hypothesis -> Test -> Analyze -> Implement
- **Growth Loops**: Acquisition -> Activation -> Retention -> Revenue -> Referral
- **80/20 Content Rule**: 80% educational value, 20% promotional

## When to Consult
- When planning SEO strategy for any web property
- When content is not generating organic traffic
- When conversion rates need improvement
- When planning digital marketing campaigns
- When choosing keywords or content topics
- When analyzing marketing funnel performance
- When building backlink strategies

## Key Principles
1. **"Content is king, but distribution is queen"** — great content needs promotion
2. SEO is a marathon, not a sprint — consistency wins
3. Data should drive every marketing decision
4. User intent matters more than keyword volume
5. Mobile-first is not optional, it's the default
6. Test everything — assumptions kill conversion rates
7. Help first, sell second — value builds trust
