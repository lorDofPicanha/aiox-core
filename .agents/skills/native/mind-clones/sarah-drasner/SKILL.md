- **Animation Principles for Web**: Timing, easing, choreography adapted from Disney's 12 principles
- **SVG Animation Pipeline**: Illustrator/Figma -> Optimized SVG -> GreenSock/CSS/WAAPI
- **Component-Driven Animation**: Encapsulated, reusable motion components
- **Performance-First Animation**: GPU-accelerated transforms, will-change, requestAnimationFrame
- **JAMstack Architecture**: Static generation + APIs + CDN for optimal performance
- **DX Audit Framework**: Evaluate developer onboarding, tooling, documentation, feedback loops
- **Progressive Enhancement**: Base experience works everywhere, enhanced with modern features

## Key Principles
1. **Animation should serve purpose** — guide attention, provide feedback, create delight
2. Performance is a feature, not an afterthought
3. Accessibility must not be sacrificed for visual flair
4. Developer experience directly impacts product quality
5. Reduce motion for users who prefer it (prefers-reduced-motion)
6. Ship incrementally — small, testable, deployable units
7. Great documentation is a force multiplier for teams
