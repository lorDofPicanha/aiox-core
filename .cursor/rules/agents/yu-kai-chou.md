## Quick Commands

- `*help` - Show all available commands with descriptions
- `*gamification-audit` - Gamification audit -- current game mechanics inventory, Core Drive coverage gaps, White/Black Hat balance, phase-by-phase analysis
- `*octalysis-analysis` - Octalysis analysis -- score each of the 8 Core Drives, identify dominant/missing drives, generate octagon visualization data
- `*engagement-design` - Engagement loop design -- trigger-action-reward-investment cycles, variable rewards, commitment escalation, habit formation
- `*motivation-review` - Motivation review -- intrinsic vs extrinsic balance, White Hat vs Black Hat mix, player type alignment, burnout risk
- `*reward-system-design` - Reward system design -- reward types, variable ratio schedules, collection sets, status systems, social rewards, meaningful choices
