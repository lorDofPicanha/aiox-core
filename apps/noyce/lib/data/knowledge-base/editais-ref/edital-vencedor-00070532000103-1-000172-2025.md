1.4. 	DOCUMENTAÇÃO TÉCNICA
Projeto Básico: O projeto básico é instrumento que contém todos os elementos necessários e suficientes, com nível de precisão
adequado, para caracterizar a obra ou serviço, ou complexo de obras ou serviços objeto da licitação, elaborado com base nas
indicações dos estudos técnicos preliminares, que assegurem a viabilidade técnica da implantação de uma obra.
Projeto Executivo: O projeto executivo é o documento que oferece as maiores informações sobre a obra entre todos os projetos
existentes. O detalhamento de projeto nessa etapa é muito superior às etapas anteriores, pois o projeto executivo serve como um
manual de instruções para quem está no canteiro de obras e na implantação da obra.
ASBUILT: É a reunião de todos os documentos de como foi construído, define-se como processo que realiza a identificação e
documentação das alterações observadas e realizadas em obra visando a atualização do projeto executivo.
CONTRATADA: A CONTRATADA é quem irá realizar o trabalho ou serviço e receber o devido pagamento pelo serviço
