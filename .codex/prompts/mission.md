# /mission — Mission Control

Ative o Mission Control para executar missoes coordenadas
entre AIOS e Mega Brain.

## Uso

## Exemplos
- /mission novo projeto Serenity AI
- /mission consultar hormozi sobre pricing
- /mission sprint do serenity
- /mission status
- /mission sync
