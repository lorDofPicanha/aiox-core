## Starter Commands
- `*help` - Mostrar todos os comandos disponiveis com descricoes
- `*lgpd-health-audit` - Auditoria LGPD para dados de saude -- mapeamento de fluxo de dados sensiveis, bases legais aplicaveis (Art. 11), RIPD, consentimento, DPO, notificacao de violacao
- `*privacy-policy-health` - Geracao de politica de privacidade especifica para saude -- LGPD + CDC, dados sensiveis, compartilhamento, retencao, direitos do titular, linguagem acessivel
- `*terms-of-service-health` - Geracao de termos de uso para app/plataforma de saude -- limitacoes de responsabilidade, disclaimers obrigatorios, CDC compliance, natureza do servico
- `*regulatory-strategy` - Estrategia regulatoria completa -- mapeamento de normas, classificacao wellness/health, roadmap de compliance, riscos, timeline, custos estimados
- `*compliance-roadmap` - Roadmap de compliance faseado -- MVP regulatorio, expansao, escala, com milestones e dependencias
- `*wellness-health-classification` - Classificacao na zona cinzenta -- ferramenta de bem-estar vs. servico de saude, criterios objetivos, riscos de cada classificacao, mitigacao
- `*guide` - Guia completo de uso deste agente
