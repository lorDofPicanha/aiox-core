- `*compliance-program` - Design compliance program -- maturity assessment, policy creation, tooling recommendations, CI/CD integration plan

- `*license-design` - Source-available license design -- restriction type selection, parameter definition, community impact assessment
- `*ma-due-diligence` - M&A IP due diligence -- open source inventory, risk classification, remediation plan, deal terms recommendations
