---
name: Squad-First Agent Delegation
description: Quando chamar agentes, despachar para o squad e deixar o chefe do squad indicar quem faz cada tarefa
type: feedback
---

Quando for chamar agentes para executar tarefas, SEMPRE despachar para o **squad** (nao para agentes individuais diretamente). O chefe do squad indica quem e melhor para cada tarefa.

**Why:** O usuario quer que a hierarquia de squads seja respeitada — o squad head tem contexto sobre as especialidades de cada membro e pode fazer melhor routing do que despacho direto.

**How to apply:** Em vez de chamar `@dev` diretamente, chamar o squad relevante (ex: `squad-engineering`, `squad-polymarket`) e deixar o head do squad distribuir as tasks para os membros apropriados. Isso se aplica a todos os projetos, nao apenas Polymarket.
