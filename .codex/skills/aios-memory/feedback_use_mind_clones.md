O time COMPLETO da AIOX Corp deve trabalhar nos projetos — incluindo os Mind Clones (experts virtuais).

**Why:** O usuario quer que os clones especializados facam analises e contribuam ativamente, nao apenas os agentes core (@dev, @qa, @architect, etc.). Os clones tem conhecimento profundo em areas especificas que os agentes core nao cobrem.

**How to apply:** Ao orquestrar qualquer projeto, identificar quais Mind Clones sao mais relevantes para cada tarefa e dispatchar eles em paralelo com os agentes core. Exemplos:
- Site luxury → Tobias van Schneider (visual), Oli Gardner (conversao), Val Head (motion)
- SEO → Rand Fishkin
- Brand → Seth Godin, April Dunford
- Frontend → Sarah Drasner, Vitaly Friedman
- Security → Bruce Schneier, Daniel Miessler
- Pricing → Patrick Campbell
- Sempre preferir clones especificos sobre agentes genericos para analises de dominio.
