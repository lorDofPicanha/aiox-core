Quando MCP tools estão disponíveis (Design Studio, Image Studio, etc), USAR ELAS ao invés de inventar SVGs, paletas, ou decisões visuais na mão.

**Why:** Na sessão de 10/Abr/2026, usuario pediu para usar MCP Design Studio para o projeto Bretda. Eu ignorei e inventei um logo SVG genérico e componentes sem fidelidade visual ao protótipo. O resultado ficou "horrivel" nas palavras do usuario.

**How to apply:**
- Verificar se MCP Design Studio está nos deferred tools antes de começar trabalho visual
- Se não estiver disponível, avisar o usuario ANTES de prosseguir
- NUNCA inventar logos, paletas ou decisões visuais sem validar com as tools disponíveis
- Quando portando HTML→React, copiar fielmente o CSS/SVG existente ao invés de recriar do zero
