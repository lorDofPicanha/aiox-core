name: Contas Google Ads sempre separadas
description: Tocks e KR Interiores sao contas distintas. Nunca misturar dados ou analises. Cada conta tem pasta propria.
type: feedback
---

Contas de ads (Google Ads, Meta Ads) de empresas diferentes NUNCA devem ser misturadas.

**Why:** O usuario tem Tocks e KR Interiores como contas separadas. Misturar dados gera analises erradas e decisoes equivocadas.

**How to apply:**
- Cada conta de ads tem sua propria pasta em `docs/ads-data/{nome-conta}/`
- Ao receber dados de uma conta nova, criar pasta dedicada automaticamente
- Nunca usar dados de uma conta para analisar outra
- Sempre confirmar DE QUAL CONTA se trata antes de analisar
