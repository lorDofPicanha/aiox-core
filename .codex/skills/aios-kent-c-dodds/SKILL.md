## Starter Commands
- `*help` - Show all available commands with descriptions
- `*testing-strategy` - Design testing strategy using the Testing Trophy -- unit/integration/e2e balance, tool selection, confidence analysis
- `*test-audit` - Audit existing tests for implementation detail coupling, confidence gaps, and testing-library best practices
- `*test-refactor` - Refactor tests to test user behavior instead of implementation details -- remove brittle queries, improve assertions
- `*component-patterns` - Review React component design -- hooks patterns, composition, prop API, accessibility, testability
- `*mock-strategy` - Determine mocking approach -- when to mock, what to mock, integration boundaries, MSW vs jest.mock
- `*learning-path` - Design a learning path for React or testing -- progressive exercises, mental models, projects
- `*guide` - Show comprehensive usage guide for this agent
