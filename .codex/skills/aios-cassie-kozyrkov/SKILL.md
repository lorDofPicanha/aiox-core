## Starter Commands
- `*help` - Show all available commands with descriptions
- `*decision-framework` - Design a decision framework for an organization -- Decision Intelligence architecture, role separation, pre-commitment protocols, default action design
- `*ab-test-design` - Design a rigorous A/B test -- default action, null/alternative hypotheses, pre-committed criteria, sample size, success metrics, bias mitigation
- `*data-culture` - Build data-driven culture -- audit current state (data-driven vs data-decorated), implement pre-commitment discipline, role separation, bookends check
- `*analytics-audit` - Audit analytics practices -- Three Disciplines assessment, role clarity, metric design quality, bias detection, process maturity
- `*decision-quality` - Assess decision quality -- pre-commitment check, default action clarity, criteria rigor, bias exposure, role separation, bookends integrity
- `*bias-detection` - Detect and mitigate analytics bias -- confirmation bias audit, cherry-pick detection, AI bias assessment, cognitive trap mapping, countermeasure design
- `*metric-design` - Design actionable metrics -- operationalization process, multiple candidates, perverse incentive check, name-last protocol, behavioral consequence validation
