[ 02 ] · FILOSOFIA CONSTITUTION · 6 ARTIGOS
MANIFESTO

"A CLI é a fonte da verdade. Dashboards observam, nunca controlam. Inteligência vive no terminal — UI é luxo, não requisito."

CLI First → Observability Second → UI Third

ARTIGO I NON-NEGOTIABLE CLI First Toda funcionalidade nova deve funcionar 100% via CLI antes de ter UI. UI nunca é requisito de operação.
ARTIGO II NON-NEGOTIABLE Agent Authority Apenas o agente certo pode executar a operação certa. Push é exclusividade de @devops. Stories só vêm de @sm/@pm.
ARTIGO III MUST Story-Driven Development Todo trabalho começa com uma story em docs/stories/. Sem story → sem implementação.
ARTIGO IV MUST No Invention Agentes não inventam features fora da story. Mantêm escopo. Pedem clarificação ao invés de assumir.
ARTIGO V MUST Quality First Quality gates pré-push obrigatórios. Lint, typecheck, testes — tudo verde antes do remote.
ARTIGO VI SHOULD Absolute Imports Nunca relativos (../../../). Sempre absolutos (@/...). Refactoring sem dor.

Pirâmide de comando — do orquestrador às lendas.

Cada tier delega para o tier abaixo. Quanto mais abaixo, mais especializado e numeroso. O Master no topo executa qualquer coisa, mas tipicamente delega. Mind Clones na base nunca acionam outros — só respondem consultas.

[ 09 ] · INFRAESTRUTURA SISTEMAS-BASE
O QUE ROLA POR BAIXO

4 sistemas core sustentam o AIOS — e ninguém vê.

Você interage com agentes. Eles interagem com esses sistemas. Cada um tem responsabilidade clara — context engine, knowledge enrichment, code registry, mind clone consultation.

SYS · 01 SYNAPSE

Context engine. 8-layer processing pipeline que decide o que vai pro context window do agente em cada turno. Domínios, rules, star-commands, context brackets. Mantém você fora do limite de tokens.

Slash: /synapse:manager

SYS · 02 HYDRA

Research + enrichment pipeline. Consome fontes externas em volume (tipicamente 1k-5k docs por run), distribui via router pra Mind Clones relevantes, gera knowledge-feeds em D:/jarvis/mega brain/knowledge-feed/. Inicialização pré-projeto.

Mode: heuristic + OpenAI fallback

SYS · 03 IDS

Incremental Development System. Entity Registry com BFS traversal de usedBy → consumers. Pre-action hooks (advisory) antes de *create/*modify: REUSE/ADAPT/CREATE recommendations + impact analysis. Health check + stats.

Cmd: *ids check/impact/register

SYS · 04 BRAIN-BRIDGE

MCP server (16 tools) que liga AIOS aos Mind Clones do Mega Brain. Tools: request_expert_consultation, get_consultation_response, publish_conclave_report, search_known_fixes, log_tool_usage.

mcp__aios-brain-bridge__*
