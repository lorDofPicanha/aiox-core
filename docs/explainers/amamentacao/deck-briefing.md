# Briefing normalizado — Deck Amamentação

## Audience
Mães gestantes/lactantes, familiares, profissionais não-médicos (enfermeiras, agentes comunitários, doulas). Brasil.

## Objective
Educar sem assustar. Reduzir desmame precoce por mitos. Empoderar busca de ajuda profissional gratuita.

## Belief shift
**De:** "Tem leite fraco, tem que dar fórmula, amamentar dói porque tem que doer."
**Para:** "Nenhum leite é fraco. Dor persistente = pega errada (resolve em consulta). Ajuda gratuita está no Disque 136."

## Story arc (persuasive)
REFRAME (mito custa desmame) → TENSION (números BR) → MECHANISM (pega = 80%) → PROOF (4 complicações com solução) → CONTRAST (mitos mortais vs verdade) → DECISION (red flags) → CTA (onde achar ajuda)

## Format
16:9 (1920×1080), HTML standalone, exportável PDF via Ctrl+P, 12 slides.

## Constraints
- Max 45 palavras visíveis por slide (regra slide-creator)
- Tom técnico-acessível, anti-pânico
- Design Ease Health (DESIGN.md em ./DESIGN.md)
- Variedade: máx 2 slides consecutivos com mesma estrutura
- Cada slide tem 1 função na jornada

## Slide-function map

| # | Function | Action title |
|---|----------|--------------|
| 01 | HOOK / cover | Amamentar sem medo, sem mito |
| 02 | REFRAME | Mitos custam mais leite que doença |
| 03 | TENSION | Brasil amamenta exclusivo só até 3,5 meses |
| 04 | MECHANISM | Uma única causa explica 80% das dores |
| 05 | PROOF #1 | Fissura cicatriza quando a pega corrige |
| 06 | PROOF #2 | Ingurgitamento: gelo (não calor), 2026 |
| 07 | PROOF #3 | Mastite: continue amamentando, não pare |
| 08 | PROOF #4 | D-MER: 14% das mães sentem, ninguém avisa |
| 09 | CONTRAST | 3 mitos que causam desmame |
| 10 | CONTRAST | 3 mitos que liberam (gripe, remédio, cesárea) |
| 11 | DECISION | Quando vai agora vs espera amanhã |
| 12 | CTA | Disque Saúde 136 · ajuda gratuita 24/7 |

## QA gates
- Narrativa: cada slide tem função única ✓
- Densidade: ≤45 palavras visíveis ✓
- Proof: evidências marcadas com fonte (ABM/SBP/OMS) ✓
- Action titles: todos fazem claim, nenhum genérico ✓
