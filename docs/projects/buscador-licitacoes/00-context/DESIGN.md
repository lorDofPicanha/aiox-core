## Logo

O logo oficial e o Chip-Radar: circuito integrado com varredura de radar e ponto de sinal. Use os assets de 07-brand-mockups/logo/.

E proibido substituir por monograma generico, letra N solta, icone abstrato de dashboard ou simbolo de chatbot.

## Estrutura UI esperada

A interface do Noyce deve parecer uma mesa operacional de licitacoes, nao uma landing page. Componentes e telas devem orbitar estes blocos:

- Feed de oportunidades.
- Match score explicavel.
- Dossie de habilitacao.
- Timeline de movimentacoes.
- Stage 5 / preclusao, com alerta de manifestacao no momento certo.
- Rail de acompanhamento para sessao, prazos, portais, evidencias e responsaveis.

## Tom

Não gritamos. Calculamos.

O produto fala com calma, precisao e densidade consultiva. O ambar acende quando ha sinal real; nao vira decoracao.

## Antipadroes

Nao usar:

- Landing page como experiencia principal.
- Tema generico de dashboard SaaS.
- Lime/terminal como direcao dominante.
- Placeholders pobres, lorem ipsum ou cards vazios sem evidencia.
- Chatbot como tela principal.
