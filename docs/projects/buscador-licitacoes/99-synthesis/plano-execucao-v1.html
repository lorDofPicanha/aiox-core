02 ▸ Sprint 1-3 — MVP Core

Ingestion + Match + Notif básica

Semanas 2-4, ~30h Breno + 30h dev.

Foco: ingestion + storage + search básico funcionando para amigo + Breno. UI minimalist, lógica completa.

01
Schema + Ingestion Skeleton
▸ 1 semana
DB OCDS-shape interno (release → tender → award, OCID ocds-aguasdf-). Migration Supabase + pgvector (halfvec) + HNSW + FTS portuguese + unaccent. Tabelas releases, parties, documents, awards, perfis_fornecedor, alertas, feedback. Inngest worker fetch-pncp-publicacao (cron 15min). CPF mask aplicado. LlamaParse worker assíncrono.
02
Match Engine + IA
▸ 1 semana
enrichLicitacao worker: download → parse PDF → resumo IA Haiku → embedding text-embedding-3-small → persist. Multi-provider LLM router (Anthropic + OpenAI fallback). Match v1: score = keyword (BM25) × CNAE × geo × valor. Perfil-fornecedor completo (baseline F3).
03
Email + UI básica
▸ 1 semana
Email digest diário Resend (top 5 matches do perfil). Web Push opcional. Dashboard Next.js: lista de matches, filtros básicos, link edital PDF. Search bar (texto → BM25 + cosine rerank).
▸ Deliverable Sprint 1-3

MVP rodando para amigo. Recebe email diário com 5 matches relevantes. Busca por keyword. Vê resumo IA + score match.

03 ▸ Sprint 4-6 — Quality + WhatsApp + LGPD

Robustez, canal, compliance

Semanas 5-7, ~30h Breno + 30h dev.

04
Robustez infra
▸ 1 semana
Docling self-host fallback (Docker worker) para overflow LlamaParse. Retry exponencial 5xx em todas fontes externas. Circuit breaker para PNCP (>3 falhas/5min, pausa 10min). Cache HTTP local 15min. Self-throttling (1 req/s baseline). User-Agent identificável: BuscadorLicitacoesDF/1.0 (+contato@dominio.br). Observability: Sentry + Vercel Analytics + log estruturado pino.
05
WhatsApp integration
▸ 1 semana
WAHA self-host (Docker) OU Cloud API ($0.005/msg). Opt-in granular: Email / WhatsApp / Web Push. Alert WhatsApp: top 1 match Tier S do dia (não spam — 1 msg/dia máx). Botão "Ver no app" → deep-link.
06
LGPD compliance
▸ 1 semana
Política Privacidade real (research-regulatoria-v1 checklist). Termos de Uso. Canal contato: privacidade@dominio.br. Cookie banner LGPD. ROPA simplificado 8 campos ANPD. DPAs Supabase/Vercel/Anthropic/Resend/Inngest/LlamaParse. Runbook notif incidente (6 dias úteis ATPP). Footer: atribuição ODbL + links Privacidade/Termos.
▸ Deliverable Sprint 4-6

MVP robusto + WhatsApp + LGPD-compliant. Pronto para 5-10 fornecedores DF testarem além do amigo.

04 ▸ Sprint 7-9 — Differentiators

OCDS, RAG chat, search semântica

Semanas 8-10, ~30h Breno + 30h dev.

07
OCDS export + API pública
▸ 1 semana
Endpoint /api/ocds/releases?date=YYYY-MM-DD retornando JSON OCDS-shape. Endpoint /api/ocds/releases/{ocid} individual. Docs Swagger/OpenAPI público. Registrar OCID prefix ocds-aguasdf- no Open Contracting Partnership namespace (custo zero). Linkable: cada match no app mostra link .ocds.
08
Chat RAG sobre edital
▸ 1 semana
Embedding por chunk de edital (semantic + RAG). Chat interface: usuário pergunta sobre o edital ("qual o prazo de entrega?", "quais documentos preciso?"). Limit: 5 chats/dia/user no MVP. Two-tier: Haiku padrão + Sonnet 4.5 quando clica "análise profunda".
09
Search semantic + recommender
▸ 1 semana
Search híbrida BM25 + cosine rerank (já mais avançada que Mercell líder Nordic). Saved searches: usuário salva query, recebe alertas. Recommender: "editais similares ao que você favoritou" (cosine vetor médio dos favoritos).
▸ Deliverable Sprint 7-9

Buscador de qualidade técnica state-of-the-art global. OCDS-compliant, RAG chat, search semântica + híbrida, multi-canal notif, LGPD-compliant. Diferenciado vs Effecti/LicitaNet/Sollicita em dimensões reais.

06 ▸ Orçamento honesto

Recalibrado por Tetlock

Tempo

  • Sprint 0: 1 semana × ~18h = 18h
  • Sprint 1-10: 11 semanas × ~12-15h = 132-165h
  • Total dev MVP: 150-183h distribuídas em 12 semanas
  • Tetlock: 14 semanas é mais realista, P=45%
  • Buffer realista +20% (planning fallacy) = 180-220h em 14-15 semanas

Custo financeiro

  • Pré-MVP (Sprint 0-10): R$0 — tudo free tier
  • Operacional fase MVP: $30-50/mês
  • Anthropic Haiku $25 + Resend free + Supabase free→Pro quando aperta + Vercel free + Inngest free + LlamaParse free
  • Operacional pós-MVP (≥10 usuários): $50-80/mês (Supabase Pro $25 + buffers)
  • Hard cap user: $80/mês operacional pessoal
▸ Governance Tocks/Bretda — não-negociável

Toda segunda-feira: Breno revisa metrics 15min

  • Tocks (saldo, CPL, conv)
  • Bretda (CPL, conv, atribuição)
  • KR (WABA fix status)

Gatilho de pausa: qualquer um em EMERGÊNCIA (saldo zerado / CPL > 2x baseline / config quebrada) → buscador pausa pelo tempo necessário. Buscador é o 5º projeto na pilha de attention. Não-negociável.

07 ▸ Quality patterns

10 padrões não-negociáveis

Estes são o que torna "best buscador" e não "yet another buscador".

▸ 01
Privacy by Default
CPF jamais entra no banco. LLM instruído a não preservar. (Sprint 0 B2, Sprint 1, Sprint 8)
▸ 02
OCDS-native interno
Schema interno é OCDS-shape, OCID universal. (Sprint 1 + Sprint 7)
▸ 03
API pública gratuita
Devs podem integrar sem permissão nossa. (Sprint 7)
▸ 04
Multi-provider resiliente
Anthropic 529 ou OpenAI down ≠ produto down. (Sprint 2)
▸ 05
Atribuição transparente
Toda fonte tem source_url + fetched_at visível. (Sprint 1)
▸ 06
No dark patterns
Cookie banner sem dark pattern (LGPD strict). Notif opt-in real. (Sprint 5+6)
▸ 07
Honest free tier
Free regional é produto real, não bait. (Always)
▸ 08
Idempotência ingestion
Ingerir 2x mesmo edital ≠ duplicar. OCID universal resolve. (Sprint 1)
▸ 09
Spot-check IA
Humano valida ≥50 primeiros resumos antes de liberar produção. (Sprint 10)
▸ 10
Observability dia 1
Sentry + logs estruturados antes de qualquer feature. (Sprint 4)
08 ▸ Lessons aplicadas

O que os clones mudaram

De Scott Alexander

  • Friend's friend test não vai acontecer agora (user disse: não monetizar). Mas estrutura de feedback fica: amigo + 2 fornecedores indicados = 3 power-users N≈3 para validar qualidade real
  • OpenTender.eu syndrome evitado — foco fornecedor pragmático ("isso é oportunidade pra mim?") explícito desde Sprint 0 (F1-F3)
  • Defer ambition: 7 ajustes → 4 P0 (Docling, halfvec/HNSW, multi-provider, schema OCDS) + 3 P1 (API pública, two-tier model, Megasoft) — não simultâneo

De Philip Tetlock

  • Timeline honesta: 10-12sem → 12-14sem +20% buffer = 14-16 semanas
  • Custo honesto: $0-40/mês → $30-50/mês
  • Checkpoint Tocks/Bretda semanal não-negociável (F7 68% pausa forçada)
  • CPF mask hard requirement (H11 recalibrado mas Privacy by Default mantém-se Sprint 0)

De Dave Snowden

  • Sprint 0 = probe phase (não kill option — refraseado para "validar fundações antes de build")
  • D-STACK é Complicated → confirmar e construir. Sem mais análise.
  • Concierge experience embedded: Sprint 0 F1-F3 captura "como amigo usaria isso manualmente" — informa Sprint 1-3 UX
  • Safe-to-fail experiments inline: cada Sprint tem deliverable testável; falha não destrói build, redireciona
