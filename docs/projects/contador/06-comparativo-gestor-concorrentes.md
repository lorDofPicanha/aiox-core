## Leitura estratégica (o ponto-chave)

O **Gestor é forte em gestão operacional / obrigações acessórias** mas **fraco no core de inteligência fiscal** (captura, auditoria, e-CAC, emissão, leitura automática). E é **exatamente esse core** que vocês querem construir como diferencial.

➡️ **Gestor = a fundação pronta do módulo "Gestão/Obrigações Acessórias" (#7 do doc 05).** Construir o CORE fiscal (captura→auditoria→restituição→ECAC→emissão) por cima/ao lado. As lacunas do Gestor batem quase 1:1 com o core que vocês querem.

⚠️ Duas listas de concorrentes distintas (2 mercados):
- **Gestão de obrigações** (esta planilha): Tareffa/Ottimizza, GClick/Omie, Confi, MakroSystem, Acessórias, **Nibo**, Neo Controle, TaskDo.
- **Captura/emissão/recuperação** (do áudio): IRIS/CIEG, **GOB**, VERI, G-TAX, Klaus, CITAX/C-TAX, Conta Azul.

1. **Reaproveitar o Gestor** como base do módulo de Gestão/Obrigações — já tem 23 features maduras, incluindo coisas não-triviais (regras de antecipação de guia, log de leitura/recebimento, controle de certidões por tipo de empresa).

3. **WhatsApp oficial + App do cliente** aparecem como lacuna recorrente → diferencial de comunicação.
4. **Preencher a matriz de preço/layout/implantação** dá munição pro pitch (o áudio já dizia: layout e praticidade de implantação importam; CIEG ganhava no comercial agressivo, não no produto).
