# Confectionery Conversion Patterns v1

These patterns convert verified customer jobs into page mechanisms. A pattern is
eligible only when the prospect dossier supplies supporting facts and media.

## Customer-job Matrix

| Customer job | Current friction to test | Web mechanism | Qualified action | Metric |
|---|---|---|---|---|
| Choose a treat now | Social/catalog browsing lacks a fast confidence layer | Product hero + availability/channel clarity | Open order channel | Order/WhatsApp click-through |
| Order for a celebration | Custom orders are buried in direct messages | Occasion page with process, lead time and examples | Request an order/quote | Qualified occasion inquiries |
| Send a gift | Packaging, message and delivery options are unclear | Gifting story + verified options | Start gift order | Gift-intent clicks/inquiries |
| Visit or collect | NAP/hours vary across third parties | Verified location, hours, route and pickup block | Route/call/pickup action | Route, call and pickup clicks |
| Trust product quality | A feed shows images but not process or proof coherently | Maker/process/ingredient narrative with real media | Continue to order/contact | CTA progression and engaged visits |
| Understand the assortment | Products are listed without intent or occasion structure | Small verified taxonomy by product/occasion | View category/order | Category-to-action rate |
| Plan an event | Catering/event capability is invisible or fragmented | Event proof, capacity/lead-time facts and inquiry path | Event inquiry | Attributable event leads |

## Page Rules

1. Declare one primary conversion goal and one dominant CTA label per prospect.
2. The first viewport must answer identity, distinctive offer, location/context
   and next action without unsupported claims.
3. Every section must have a row in the prospect value thesis: customer job →
   pain/objection → mechanism → action → metric.
4. Occasion/product navigation is preferable to a generic card wall when the
   public offer supports it.
5. Social proof is a research input unless an exact, traceable review is cleared
   for display; invented testimonials are forbidden.
6. WhatsApp is a conversion destination, not the entire information
   architecture. The page should qualify intent before the click.
7. Mobile ordering/contact actions remain reachable without hiding essential
   price, lead-time, pickup or location context.

## Prospect-specific Direction Tests

- **Product-icon direction:** valid when one verified product has strong visual
  distinction and recurring public prominence.
- **Occasion atelier direction:** valid when custom cakes, events, gifting or
  celebration orders are publicly evidenced.
- **Heritage/local direction:** valid when longevity, family/maker history and
  regional products are primary-source verifiable.
- **French/luxury direction:** valid only when the prospect's own positioning,
  offer and brand signals support it; visual taste alone is insufficient.
- **Playful/social direction:** valid when official language, packaging and
  product naming consistently support that personality.

## ROI Scenario Contract

```text
qualified visits × contact rate × close rate × average order/inquiry value
= modeled incremental opportunity
```

Each input is conservative/base/optimistic and marked as observed, sourced,
assumed, or `unknown_not_public`. The output is a hypothesis, never a revenue
promise. Recommended post-launch measures are primary CTA clicks, WhatsApp
clicks, calls, route requests, occasion inquiries and attributable orders.
