# Anti-clone Matrix v1

**Status:** measurement framework initialized; prospect rows open until mockups
exist.

## Hard Limits Against Any Single Benchmark

| Dimension | Limit | Calculation |
|---|---:|---|
| Color | ≤85% | Matches among six semantic roles using CIEDE2000 `ΔE00 ≤ 10` |
| Typography | ≤75% | Matches among ten family/weight/scale attributes |
| Layout | ≤60% | Identical features among ten declared composition features |

Exact copy, media reuse, distinctive trade-dress imitation, or a page-by-page
replica fails regardless of numeric score. Organism-level composition must draw
from at least three independent references.

## Layout Features

1. Section order.
2. Hero composition.
3. Navigation pattern.
4. Product presentation.
5. Occasion/offer block.
6. Proof block.
7. Location block.
8. Primary CTA placement.
9. Footer composition.
10. Distinctive decorative motif.

## Cross-prospect Guard

The three mockups must also be compared with one another. Reusing invisible
accessibility/technical primitives is allowed; repeating the full-page skeleton,
hero geometry, section rhythm, typography pair, or decorative language is a
hard `REFINE`.
