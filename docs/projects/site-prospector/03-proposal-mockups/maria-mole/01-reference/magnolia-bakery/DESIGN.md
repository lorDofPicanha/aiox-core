## 1. Visual Theme & Atmosphere

Magnolia Bakery's system is anchored in bakery nostalgia made crisp for e-commerce: a pale mint identity color, deep green typography, soft pastry pastels, and occasional berry-red commerce accents. The brand color is not a generic web link hue; it is the mint that appears in badges, shapes, checkbox states, and button inversions, paired with the dark green that gives the page its recognizable bakery-shop authority.

Typography carries the charm. `Gatefold Demi` handles the big, rounded display moments; `Gt Alpina` adds a warmer editorial serif for subheads; `Ambit` is the workhorse for body copy and CTAs. The system avoids tight tracking and relies on font shape, size contrast, and uppercase button labels for personality.

Surfaces are mostly white and product-forward, with mint overlays, transparent image buttons, and Shopify-style elevation available for dropdowns and modal states. The most distinctive choice is the dark-green button that flips to mint on hover, creating a confectionery color exchange instead of a typical darker-hover CTA.

**Key Characteristics:**

- Magnolia mint `#bae8d4` is the identity anchor.
- Deep green `#00211a` is the default text and primary button fill.
- `Gatefold Demi` owns display headlines; do not substitute generic slab or sans.
- `Ambit` gives body copy and buttons a soft, rounded retail tone.
- Pastel shape colors support product photography rather than overpower it.
- Buttons are pill-like at `20px`, not square and not fully rounded.
- Inputs are compact, material-filled controls with `2px` radius and animated underlines.
- Elevation exists for dropdowns and overlays, but product cards stay restrained.
- The visual language is premium bakery retail: generous image space, warm copy, and controlled color.

### Color Philosophy

Most UI should feel light, edible, and photographic, with color used as flavor accents around product imagery.

## 3. Typography Rules

### Font Family

The source declares several families, but the Magnolia theme layer uses a clear trio: `Gatefold Demi` for display, `Gt Alpina` for editorial subheads, and `Ambit` for body and buttons. `Libre Franklin` remains in the system for labels, inputs, and small uppercase retail UI. There is no true monospace face; use `Libre Franklin` with tabular-number features only when numeric alignment is needed.

- Use `Gt Alpina` sparingly for editorial softness, especially near product photography.
- Use `Libre Franklin` for small utility labels and badges, not for hero copy.

## 5. Layout Principles

### Spacing System

Magnolia uses a pragmatic Shopify spacing scale rather than a single strict grid. The strongest repeated values are `6px`, `12px`, `20px`, `30px`, and `55px`: small badge padding, input horizontal padding, section/control gaps, mobile button padding, and desktop button padding.

### Grid & Container

The detected primary container is `1352px`, with common supporting widths at `1140px`, `595px`, and product tile widths around `250px` to `260px`. Order-now sections are image-and-copy commerce blocks, with product photography carrying the first visual read and text/CTA blocks using the deep-green/mint system.

### Whitespace Philosophy

Whitespace should feel like bakery display spacing: generous enough for each dessert image to feel special, but not sparse like a software landing page. Keep content modules clear and readable, with enough room around CTAs for the pill shape to breathe.

Mobile reduces type and button padding but keeps the same brand contrast. Do not compress product images into dense dashboards; the page needs large image moments and clear ordering choices.

### Border Radius Scale

- `0px`: Product badge ribbons and reset controls.
- `2px`: Inputs and product/content tiles.
- `20px`: Primary, secondary, and image buttons.
- `25px`: Header/nav rounded containers detected in component scan.
- `9999px`: Carousel arrows and circular icon controls only.

## 6. Depth & Elevation

| Level | Treatment | Use |
|---|---|---|
| Flat | White surface, no shadow | Main page background and simple product sections |
| Ambient | `#cccccc` border on `#ffffff` | Product/content tile boundaries |
| Standard | `--box-shadow`: `0 2px 1px -1px rgba(0, 0, 0, 0.2), 0 1px 1px 0 rgba(0, 0, 0, 0.14), 0 1px 3px 0 rgba(0, 0, 0, 0.12)` | Cards or controls that need slight lift |
| Elevated | `--box-shadow-elevated`: `0 5px 5px -3px rgba(0, 0, 0, 0.2), 0 8px 10px 1px rgba(0, 0, 0, 0.14), 0 3px 14px 2px rgba(0, 0, 0, 0.12)` | Dropdowns, selects, modal-adjacent layers |
| Deep | `0 0 50px 0 rgba(0,0,0,.5)` or dark overlays | Modal and image-overlay emphasis |
| Ring | `0 0 0 5px #19f` | Keyboard-visible focus only |

### Shadow Philosophy

Depth is available but not decorative. Magnolia relies on product photography, white surfaces, and mint/dark-green contrast first; shadows appear mostly for functional layers such as dropdowns, overlays, and modals. When building new UI, prefer border plus surface contrast for normal cards and reserve stronger elevation for controls that float above the shopping flow.

## 7. Do's and Don'ts

**Do:**

- Do make Magnolia mint `#bae8d4` the identity signal in badges, hover states, shapes, and brand accents.
- Do set primary CTA buttons with `#00211a` fill, `#bae8d4` text, `20px` radius, and uppercase `Ambit`.
- Do use `Gatefold Demi` for large headings; it is the source of the bakery-retail personality.
- Do keep body copy in `Ambit` and deep green `#00211a`.
- Do use `Gt Alpina` for gentle editorial subheads near food photography.
- Do keep product badges ribbon-like with square edges and the angled tail motif.

**Don't:**

- Don't make `#b32e4e` the brand primary just because it is named `--primary-button-background`; Magnolia's identity is mint plus deep green.
- Don't use pure black `#000000` for headings when `#00211a` is the declared heading and body color.
- Don't replace `Gatefold Demi` headlines with `Open Sans`; `Open Sans` appears in older/root tokens, but the Magnolia theme layer overrides display type.
- Don't turn product badges into rounded pills; the source badge is square with a triangular ribbon tail.
- Don't use large `16px` card radii; product and tile radius is `2px`.
- Don't add blue link styling by convention; links and CTAs stay in the deep-green/mint palette unless a focus ring is explicitly needed.
- Don't apply backdrop blur everywhere; the detected blur belongs to header/overlay treatment, not every card.
- Don't use heavy shadows on ordinary product tiles; reserve `--box-shadow-elevated` for dropdowns and overlays.

## 8. Responsive Behavior

### Breakpoints

| Name | Width | Key Changes |
|---|---:|---|
| Tiny control edge | 240px / 241px | Rare micro-control threshold |
| Mobile | 767px | Mobile type scale, smaller button padding, mobile nav colors |
| Tablet | 768px | Tablet typography and layout begin |

| Wide content | 1100px / 1200px | Wider marketing/content layouts |
| Large desktop | 1279px / 1280px | Desktop control tuning and large image layouts |
| Max container | 1400px | Full-width container ceiling near `1352px` |

### Touch Targets

Buttons use `44px` height on desktop/tablet and `40px` on mobile, with horizontal padding reducing from `55px` to `30px`. Inputs use a compact `38px` height and need clear label spacing because the material-filled labels animate inside the control.

### Collapsing Strategy

Desktop uses larger `Gatefold Demi` headings (`65px`, `54px`, `42px`) and an `80px` header. Mobile keeps the brand type but downscales display headings to roughly `38px`, body copy to `16px`, and header/cart states toward `60px`. Multi-column product/order blocks should collapse into single-column image-first sections.

### Image Behavior

Product and order imagery should remain generous and inspectable. On mobile, stack image above copy or alternate cleanly; do not crop desserts into abstract backgrounds. Badges and CTAs should stay readable over or adjacent to photography, using transparent image-button variants only when contrast is guaranteed.
