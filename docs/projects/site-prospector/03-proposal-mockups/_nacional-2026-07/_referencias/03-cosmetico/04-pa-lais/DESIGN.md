## Como usar este blueprint

Referência estrutural para o nicho **Cosméticos**. Padrão ADR-0004: a composição
aprovada é preservada; troca-se a identidade (tokens da marca), o conteúdo real e a mídia
first-party do cliente.

**Gate anti-clone (não-negociável):** similaridade máxima com esta referência —
cor ≤85% · tipografia ≤75% · layout ≤60%. É por isso que o nicho tem 5 referências:
cruzar fontes independentes é o que impede virar cópia de uma só.

**Teste de forkability antes de usar como fork:** medir o CSS externo. CSS minúsculo =
layout JS-driven que colapsa sem os bundles (caso `nueno`). Ver [[reference-forkability-test]].
