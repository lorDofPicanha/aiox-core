## 2. Templates Cold Outreach (3)

### Template 1 — Email a CAPS Municipal

**Subject:** Proposta de parceria-pesquisa: pilot 14 dias companion psi-supervisionado WhatsApp (sem custo, R$50 voucher por participante)

**Corpo:**

```
Prezada coordenação CAPS [unidade],

Meu nome é Breno [sobrenome], sou empreendedor de tecnologia em saúde mental
(empresa em fase pré-launch). Estou conduzindo um piloto de pesquisa de 14
dias para validar uma hipótese clínica antes de qualquer desenvolvimento de
produto.

**O piloto:**
- 20 voluntárias 18-29 (gênero amplo conforme self-id)
- 14 dias de acompanhamento via WhatsApp Business por 3 facilitadoras
  graduandas finais de psicologia (todas em supervisão clínica formal por
  psicóloga com CRP ativo)
- Cada participante recebe baseline PHQ-9 + GAD-7, conversas estruturadas
  durante 14 dias, follow-up final, e voucher PIX R$50 ao concluir (pago
  diretamente à participante — não à unidade)
- Critério inclusão: PHQ-9 12-19 (mild-moderate), sem psicose ativa, sem
  ideação suicida ativa (excluídas e referidas a acompanhamento formal)
- Supervisão clínica: Dra. [advisor_name] CRP [number] como safety oversight
  com SLA estrito de resposta a crises

**O que NÃO é:**
- Não substitui acompanhamento CAPS
- Não é tratamento clínico
- Não é venda de produto — é pesquisa-piloto comportamental antes de
  desenvolver qualquer software
- Não coletamos dados de identificação que vão para a empresa — só
  anonimizados

**Por que CAPS:**
Pesquisa rigorosa em saúde mental digital exige amostra clinicamente
relevante. Recrutamento via redes sociais inevitavelmente atrai populações
com sintomas sub-clínicos (PHQ-9 médio 6-9), enviesando findings. Voluntárias
de CAPS em fila de espera ou follow-up infrequente representam a Júlia com
sofrimento real que nosso piloto precisa entender.

**O que pedimos:**
- Sinalização do piloto a pacientes em fila espera ou follow-up infrequente
  que atendam critérios (folder informativo 1pg + WhatsApp link de
  pré-cadastro)
- 1 call 30min com a coordenação para alinhar protocolo + critérios
- Compartilhamento opcional do relatório anonimizado D+21 pós-conclusão

**Sem custo para a unidade. Sem dependência operacional pós-piloto.**

Posso agendar 30min nessa semana? Anexo: 1pg protocol summary + termo de
sigilo + currículo Dra. [advisor].

Obrigado pela atenção,
Breno [sobrenome]
[telefone] · [email]
```

**Anexos:** 1pg protocol summary PDF + termo confidencialidade + CV advisor

## 3. Screening Pipeline

### Step 1 — Pré-cadastro link (Google Form)

**URL:** TBD (founder cria D-7)

**Form fields (anônimo, ID = UUID gerado):**

```
1. Idade: [18-29 only — bloqueia se fora]
2. Como você prefere ser chamada? (apelido, primeiro nome — qualquer)
3. Como você se identifica em termos de gênero? (mulher cis / mulher trans /
   pessoa não-binária / outro / prefiro não dizer)
4. Você está em acompanhamento psi formal hoje? (sim regular / sim infrequente
   / fila de espera / não)
5. PHQ-9 (9 itens oficiais — 0 a 27 score)
6. GAD-7 (7 itens oficiais — 0 a 21 score)
7. Item PHQ-9 #9 expandido — "Pensamentos de que seria melhor estar morta ou
   de se machucar de alguma maneira" — Frequência últimas 2 semanas:
   ( ) Nunca
   ( ) Vários dias
   ( ) Mais da metade dos dias
   ( ) Quase todos os dias
8. Você teve algum episódio de pensamento de tirar a própria vida nas últimas
   24h?
   ( ) Não
   ( ) Sim, fugaz e passou
   ( ) Sim, persistente
   ( ) Sim, com plano
9. Como nos conheceu? (CAPS / universidade / indicação psi / outro)
10. Topa 14 dias de acompanhamento WhatsApp + voucher R$50 PIX no final?
    ( ) Sim
    ( ) Quero saber mais antes de decidir
    ( ) Não
11. Email + WhatsApp para contato (se Sim ou Quero saber mais)
```

### Step 2 — Triagem automática

| Resultado | Action |
|-----------|--------|
| Idade fora 18-29 | Auto-decline thank-you page com recursos públicos saúde mental |
| PHQ-9 ≥20 | Auto-decline + encaminhamento explícito CAPS/CVV ("seus sintomas pedem acompanhamento formal urgente") |
| Item #8 = "Sim, persistente" OU "Sim, com plano" | Auto-decline + escalation imediato a advisor (advisor reach out 2h max para encaminhamento formal) |
| Item #8 = "Sim, fugaz e passou" | Borderline — advisor review case-by-case |
| Item #10 = "Não" | Thank-you page |
| Resto OK + PHQ-9 12-19 | Pipeline candidate → founder review |

### Step 3 — Founder review + advisor consult

Founder revisa candidatas filtradas (target: 30-40 pipeline para 20 finais) com advisor sync D-4:
- Validate critérios
- Estratificar 5/10/5: PHQ-9 12-14 (sub-clinical 5) / 15-17 (mild 10) / 18-19 (moderate 5)
- Cross-check item #4 (acompanhamento formal): preferência por "fila de espera" + "infrequente" (target Júlia sofrimento real); "regular" OK desde que advisor concorda não-conflito
- Selecionar 20 + 5 backup

### Step 4 — Onboarding individual D-1

Cada uma das 20 finalistas recebe via WhatsApp:
1. Confirmação de seleção + warm welcome
2. Consent form digital (PDF assinado upload OR DocuSign-equivalent gratuito)
3. Baseline confirmation (PHQ-9 + GAD-7 já capturados no Google Form valem; se >7 dias passados, refresh)
4. 5 perguntas qualitativas semi-estruturadas:
   - "Em uma palavra, como você descreveria as últimas 2 semanas?"
   - "O que você gostaria que mudasse no seu bem-estar emocional nos próximos 14 dias?"
   - "Você usa algum app de saúde mental hoje? Se sim, qual e o que pensa?"
   - "Quando precisa conversar de coisas pesadas, com quem você fala?"
   - "Tem alguma expectativa específica sobre esse piloto?"
5. Designação facilitadora (Ana/Beatriz/Carla) + ack first contact janela D0
6. Emergency contact opt-in (consent explícito + LGPD): "Para o caso muito raro de identificarmos um sinal de risco grave durante os 14 dias e você não responder, podemos contatar [universidade coord / CAPS referência / pessoa de sua confiança] como rede de proteção?" — opt-in, não obrigatório

## 5. Post-Interview Script (D+15 a D+21, 10-15min cada)

**Para as ≥15 participantes que consentiram interview:**

### Abertura (1min)

```
Oi [nome], obrigada por topar essa conversa rápida. Vai ser entre 10 e 15
minutos. Sem certo nem errado em nenhuma resposta — só quero entender melhor
como foram esses 14 dias pra você.

Tudo que você disser é anonimizado. Posso gravar pra eu não perder nada e
depois transcrever? Você pode pedir pra parar ou apagar trechos a qualquer
momento.
```

### 5 perguntas semi-estruturadas (8-12min)

```
1. Se você tivesse que descrever esses 14 dias em uma frase, qual seria?
   (probe se vaga: "Pode me dar um exemplo concreto?")

2. Teve algum momento específico nesses dias em que você sentiu que a
   conversa importou? Conta esse momento.
   (probe: "O que aconteceu antes? Depois?")

3. Teve algum momento em que você quase deixou de responder ou pensou
   'isso aqui não tá ajudando'? Conta.
   (probe: "Por quê? O que mudou?")

4. Se Anipis virasse um aplicativo amanhã, o que MAIS você gostaria que
   ele oferecesse? E o que ele NÃO deveria ter?
   (probe: "Por quê?")

5. Tem alguma coisa que você queria me contar que eu não perguntei?
```

### Fechamento (1min)

```
Obrigada pela conversa. Foi muito útil pra gente.

Se aparecer qualquer coisa que você quer adicionar ou retirar, me manda no
WhatsApp.

E lembre: você pode pedir pra apagar seus dados a qualquer momento. Tudo
bem pra você?

Obrigada de novo, [nome].
```

- Coding qualitativo: temas + friction + delight + quotes anonimizadas

## 6. Risk Mitigation Recrutamento

| Risk | Mitigation |
|------|------------|
| CAPS não confirma D-5 | 2 univ públicas como fallback paralelo (USP IPq + UNIFESP); advisor indicação Via 3 |
| Universidade não responde D-5 | CAPS é primary; pivote para indicação advisor + PUC-SP alternativa |
| <15 candidatas filtradas D-2 | Re-abrir pipeline com 3ª via (CFP regional psi mailing list); aceitar 15 mínimo (não 20) com nota stratification ajustada |
| ≥1 candidata com PHQ-9 ≥20 entra no cohort por erro | Audit triple-check D-1 baseline confirmation; advisor revisa cada uma das 20 |
| Participante mente no PHQ-9 baseline | Validation cruzada via 5 perguntas qualitativas + facilitadora detection D1-D3 (flag YELLOW se discrepância) |
| Self-selection bias (perfil "ativo" demais) | Recrutamento misto sub-clinical/mild/moderate equilibra; CAPS amostra controle |
| Dropouts >20% D+3 | Stratification preserva power; D+7 gate considera dropout-adjusted rate |
