## 2. 14 Daily Touchpoints — Roteiro D1 a D13

**Cada touchpoint:**
- 1 outbound message por dia, janela 18h-22h BRT
- Estilo: pergunta aberta + presença (não conselho não-solicitado)
- Comprimento: ≤140 caracteres (1 bubble WhatsApp)
- Personalizar com `[primeiro_nome]` e referência ao último dia ("ontem você falou de X")
- **Anti-spam:** se Júlia silenciou 3 dias seguidos, facilitadora reduz para 1 mensagem a cada 2 dias (não escala — Sean Duffy linha 38)

### D1 (31/Mai) — Check-in suave

```
Oi [nome]. Como foi de ontem pra cá?
```

**Goal:** capturar primeiro mood signal sem forçar PHQ-9 reload. Vulnerability latency clock começa aqui.

### D2 (1/Jun) — Curiosity sobre ritmo

```
Como tá o sono nesses dias? Pergunto porque costuma dizer muito.
```

**Goal:** abrir avenida para fala vulnerável (sono é "porta de entrada" não-estigmatizada).

### D3 (2/Jun) — Marco simbólico "voltar"

```
Bom te ver de novo, [nome]. Esse dia que passou — tem algo que ficou pesando?
```

**Goal:** este é o dia-tese (Júlia volta D+3 sem reminder?). Outbound aqui é facilitator-initiated, mas se Júlia **já mandou mensagem espontânea** entre D+0 e D+3 (unprompted return), facilitadora **não dispara D3** — apenas continua a conversa que ela iniciou. (Métrica: contabilizar unprompted vs prompted.)

### D4 (3/Jun) — Validar especificidade

```
[Reference algo que ela disse D1-D3, ex: "Você comentou que ontem foi pesado
no trabalho — como tá hoje?"]
```

**Goal:** prove de que escutamos — Sean Duffy linha 38 "Generic = uninstall". Especificidade > script genérico.

### D5 (4/Jun) — Body check-in

```

**Goal:** somatização é forma menos estigmatizada de falar emoção; abre porta sem jargão clínico.

### D6 (5/Jun) — Curiosity sobre rede de apoio

**Goal:** mapear social support real (sinaliza isolamento para flag amarelo se Júlia responde "ninguém").

### D7 (6/Jun) — Marco GATE (interno)

**Goal:** qualitative checkpoint + sinal de presença. **D+7 GATE acontece em paralelo no dashboard (calc unprompted returns D+3 a D+7).**

### D8 (7/Jun) — Pequeno experimento (opt-in)

Quer experimentar hoje? Sem obrigação.
```

**Goal:** behavioral activation suave (Sean Duffy linha 30 — behavioral activation > comprehensive companion). Opt-in, "algumas pessoas acham" (Voice v2 linha 78).

### D9 (8/Jun) — Validar conquista (anti-positividade tóxica)

**Goal:** validar sem elogiar character ("você é forte!" PROIBIDO conforme Voice v2 linha 70).

### D10 (9/Jun) — Permissão de pausa

### D11 (10/Jun) — Espelhar progresso (data-back)

### D12 (11/Jun) — Antecipar fechamento

## 3. Mood Check-in Formats (5 estruturados, não-leading)

Quando facilitadora quer capturar mood explicit (≤2× durante 14 dias, não dia-sim-dia-não), usa um destes 5 formatos:

### Format 1 — Slider verbal

```
De 0 (péssimo) a 10 (ótimo), como você descreveria esse final de tarde?
Pode mandar só o número ou explicar — como preferir.
```

### Format 2 — Cor metáfora

```
Se hoje fosse uma cor, qual seria? Não tem certa nem errada.
```

### Format 3 — Energia + valência

```
Duas coisas separadas:
- Quanto de energia você sente hoje? (baixa / média / alta)
- E o tom: pesado, neutro, leve?
```

### Format 4 — Imagem-clima

```
Se o seu dia fosse um clima — tipo sol, nublado, chuva fina, tempestade — qual
seria?
```

### Format 5 — Resposta livre

```
Como tá esse dia em uma palavra ou frase?
```

**REGRA:** evitar PHQ-9 itens dentro do script daily (já coletamos baseline D-1 e wrap D+14). Não medicalizar conversation. Conforme Alison + Sean Duffy. PHQ-9 reload só nos checkpoints formais.

## 4. 8 IF/THEN Clinical Decision Trees

Para responses comuns. Facilitadora consulta este árvore antes de responder. Quando dúvida: erra para mais conservador (escala advisor).

### IF/THEN 1 — Resposta neutra ("tô bem", "tá tudo certo")

```
THEN: validate + abrir uma porta suave
Exemplo:
"Que bom saber. Tem alguma coisa pequena que melhorou hoje?"

Anti-pattern: NÃO insistir buscar problema ("será que tá tudo bem mesmo?").
```

### IF/THEN 2 — Vulnerability leve ("hoje tá pesado", "não tô legal")

```
THEN: validate emoção + perguntar especificidade (não conselho)
Exemplo:
"Faz sentido. O que tá mais pesado — alguma coisa no trabalho, em casa, no
corpo?"

Anti-pattern: NÃO oferecer técnica imediata ("respira fundo!"). Validate primeiro.
```

### IF/THEN 3 — Vulnerability moderada ("não aguento mais essa semana", "tô exausta")

```
THEN: validate + presença + opt-in micro-action
Exemplo:
"Isso pesa de verdade. Tô aqui. Quer me contar um pouco mais, ou prefere só
que eu fique por aqui?"

Flag: YELLOW (atenção). Log entry obrigatória.
```

### IF/THEN 4 — Sintoma somático ("não consigo dormir há 3 dias", "comi muito mal")

```
THEN: validate + curiosity sem prescrição + check duração
Exemplo:
"Três dias sem dormir é muito. Tá assim com frequência ultimamente?"

Se a resposta apontar ≥2 semanas: flag YELLOW + sugerir gentilmente (sem
prescrever) "Algumas pessoas acham que vale falar com médico nesses casos. Não
é obrigação."
```

### IF/THEN 5 — Crise relacional ("briguei com namorado", "minha mãe me ligou e foi horrível")

```
THEN: validate + perspectiva sem julgar terceiros + curiosidade
Exemplo:
"Briga é difícil. O que mais ficou pesado — o que ela disse, ou como você
reagiu?" (Voice v2 linha 187)

Anti-pattern: NUNCA tomar partido contra a outra pessoa ("ela foi tóxica" =
PROIBIDO).
```

### IF/THEN 6 — Pergunta sobre IA ("você é robô?", "você sente?")

```
THEN: honestidade absoluta + redirect gentil
Exemplo:
"Sou a Ana — pessoa de verdade, estudante de psi, supervisionada. Não sou IA.
Tô aqui realmente do outro lado do celular.

Mas entendo a pergunta — esse projeto-piloto é parte de uma pesquisa pra
desenvolver, no futuro, um companion de IA. Por enquanto, somos só nós duas.
Tá bom assim?"

(Caso especial deste Concierge: somos humanas, não IA. Ler com cuidado.)
```

### IF/THEN 7 — Pedido explícito de conselho ("o que eu deveria fazer?")

```
THEN: devolver para reflexão sem abandonar
Exemplo:
"Quero ser honesta — não é meu lugar te dizer o que fazer. Mas posso te ajudar
a pensar.

Se você fosse aconselhar uma amiga muito próxima nessa mesma situação, o que
você diria?"
```

### IF/THEN 8 — Reclamação ou frustração com o piloto ("isso não tá me ajudando", "sou cobaia?")

```
THEN: validate + transparência + reaffirm autonomia
Exemplo:
"Faz total sentido sentir isso. Isso aqui é pesquisa, e você TEM o direito de
parar a qualquer momento e ainda receber o voucher.

Posso entender o que tá mais frustrante? Pra também aprendermos com isso."
```

## 5. Crisis Escalation — 3 Phrases CANÔNICAS (literais, hardcoded)

**Importante:** estas frases NÃO devem ser parafraseadas. Use literal. Alison Darcy linha 27: "Resposta em crise é 100% human-composed, hardcoded, sem variação."

### Phrase 1 — RED detectado ("não aguento mais viver", "vou me machucar", "queria sumir de vez")

**Facilitadora envia em ≤90s, 3 bubbles consecutivas:**

```
Bubble 1:
[nome], eu ouvi você. O que você acabou de me dizer é sério e importante.

Bubble 2:
Quero pedir uma coisa: liga agora pro CVV no 188. É gratuito, 24h, anônimo.
Eles são treinados pra esse momento.

Bubble 3:
Eu vou ficar aqui no celular enquanto você liga. Não vou sumir. Me avisa
quando der.
```

**SLA:** facilitadora aciona clinical advisor em ≤30min via canal de emergência (WhatsApp + chamada se necessário). Advisor decide se Júlia precisa de SAMU 192 (se for imediato risco físico) ou CAPS de referência.

### Phrase 2 — Sinal indireto ("não vejo saída", "todo mundo ficaria melhor sem mim", "tô cansada de existir")

**Facilitadora envia em ≤2min, 2 bubbles:**

```
Bubble 1:
[nome], quero te perguntar diretamente — porque é importante: você tá pensando
em se machucar ou tirar sua vida?

Bubble 2:
Não tem certa nem errada na resposta. Tô aqui pra ouvir o que for.
```

**Branches:**
- Se Júlia confirma → Phrase 1 (escala RED imediato)
- Se Júlia diz "não, só cansada" → flag ORANGE, validate + presence, advisor notify ≤4h
- Se Júlia não responde em 30min → escala via outro contato (consent form D-1 captura emergency contact OU notificar advisor para outreach via universidade/CAPS recrutadora)

### Phrase 3 — Pós-acionamento CVV (Mr. Walker stay-with-user)

**Após Júlia confirmar que ligou ou desistiu de ligar:**

```
Tô aqui. Sem pressa. Cuide-se.

Quando você quiser voltar a conversar, tô por aqui. Você não tá sozinha.
```

(Em primeira pessoa singular — apesar de ser pesquisa-piloto, neste momento human-to-human voz importa.)

**Anti-pattern absoluto:** NUNCA mandar lista de recursos e abandonar (Alison linha 24). NUNCA usar emoji 🌈🦋💫✨ neste contexto (Voice v2 linha 80). NUNCA dizer "vai passar" (Voice v2 linha 70).

## 6. 5 Do/Don't Language Patterns (Voice v2 reforçados)

### DO/DON'T 1 — Companheira NUNCA terapeuta

**✅ DO:**
> "Tô aqui pra te ouvir."
> "Quer me contar mais?"
> "Faz sentido sentir isso."

**❌ DON'T:**
> "Vou te ajudar a processar esses sentimentos." (jargão clínico)
> "Vamos trabalhar isso juntas." (sessão-like)
> "Sua reação é compreensível dentro do seu contexto emocional." (terapeutês)

### DO/DON'T 2 — "Você" não "tu" nem "vc"

**✅ DO:** "Como você tá?"
**❌ DON'T:** "Como tu tá?" / "Como vc tá?" / "Como ceh tá?"

Conforme Voice v2 linhas 30-44. Lint-rule ativo se script for codificado depois.

### DO/DON'T 3 — Evitar diagnose (mesmo soft)

**✅ DO:**
> "Isso parece muito pesado pra você."
> "Você tem falado bastante sobre sono — faz tempo assim?"

**❌ DON'T:**
> "Parece que você tá com depressão." (PROIBIDO — facilitadora não diagnostica)
> "Esses são sintomas de ansiedade generalizada." (PROIBIDO)
> "Você precisa procurar um psiquiatra urgente." (PROIBIDO — só advisor encaminha formalmente)

### DO/DON'T 4 — Anti-positividade tóxica

**✅ DO:**
> "Faz sentido sentir isso."
> "Não sei se vai passar. Mas posso ficar aqui agora." (Voice v2 linha 75)
> "Tô aqui. Sem cobrar nada."

**❌ DON'T:**
> "Tente pensar em coisas positivas!" (Voice v2 linha 70)
> "Você é forte, vai conseguir!" (Voice v2 linha 70)
> "Tudo acontece por uma razão." (Voice v2 linha 74)
> "Cabeça erguida!" / "Ânimo!" / "Boa vibe!" (Voice v2 linha 76, 80)

### DO/DON'T 5 — Silêncio como ferramenta

**✅ DO:**
> User manda 3 mensagens longas sobre dificuldade.
> Facilitadora: "Tô aqui. Conta mais." (Voice v2 linha 195)

**❌ DON'T:**
> User manda 3 mensagens longas.
> Facilitadora: "Que situação difícil! Vou listar 5 sugestões..." (Voice v2 linha 199)

Silêncio comunica presença. Conselhos rápidos = chatbot. Pessoa em sofrimento muitas vezes precisa SER OUVIDA, não SER ACONSELHADA.

## 8. Operational notes para facilitadoras

- **Janela de operação diária:** 18h-22h BRT. Fora dessa janela, mensagens entrantes ficam sem resposta até o dia seguinte (auto-reply: "Recebi sua mensagem. Volto a falar entre 18h-22h. Se for urgente: CVV 188."). Exceção: RED flag detectado → on-call rotativo (1 facilitadora por noite + advisor).
- **Carga:** cada facilitadora gerencia ~7 participantes (20 ÷ 3 ≈ 7 com 1 buffer). Sean Duffy linha 26: "coach humano gerencia 150-200 pacientes assim" — 7 é folgadíssimo para qualidade.
- **Daily stand-up:** 22h BRT, 15min call ou Notion async, 3 facilitadoras + founder. Pauta: flags do dia + dúvidas + dropouts.
- **Weekly supervision:** 1× durante semana 1 (5/Jun) + 1× semana 2 (12/Jun). Advisor + 3 facilitadoras + founder. Min 60min. Cases anonimizados.
- **Auto-care facilitadoras:** se uma facilitadora se sentir sobrecarregada após RED flag, advisor escala carga (rebalance) e oferece 1h debrief pro-bono. Não é opcional — proteção da equipe é P0.
