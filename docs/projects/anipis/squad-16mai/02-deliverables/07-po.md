## 6. Acceptance Criteria Patterns — 5 Reusáveis

Para evitar AC inconsistente entre stories. Pax dicta: toda story tocando tema X usa pattern X.

### Pattern A — Crisis Routing AC (qualquer story que toca pipeline crise)
```
- AC: Mensagem classificada como RED bypassa LLM em 100% dos casos (assert via test)
- AC: Resposta pre-validada de `crisis_responses` retornada com latência <500ms
- AC: Evento gravado em `crisis_events` com {user_id, level, keywords_matched, timestamp, response_id}
- AC: Audit log imutável (append-only, retenção 5a) escrito em `audit_safety`
- AC: Notificação interna para canal #crisis-monitor (Slack/Discord) em <2s
- AC: Adversarial test suite 50+ cenários PASS (incluir negações, eufemismos, code-switching PT/EN)
```

### Pattern B — LGPD AC (qualquer story tocando dado pessoal)
```
- AC: Consentimento granular checado antes de qualquer write (consent.{purpose} = true)
- AC: Operação logada em `audit_lgpd` com {user_id, action, legal_basis, timestamp, ip_hash}
- AC: Endpoint expõe export do dado afetado (JSON + CSV) — extensão Art. 18 V
- AC: Documentação na privacidade atualizada — referência à story ID
- AC: Teste compliance automatizado (M4-018) cobrindo cenário positivo + negativo
- AC: RIPD/DPIA seção referenciando o tratamento (atualização incremental)
```

### Pattern C — Design System Token AC (qualquer story de UI)
```
- AC: Zero hardcoded color/spacing/font-size — 100% via design tokens (`styles/tokens.css`)
- AC: Componente respeita limite 100 linhas — quebrar em subcomponentes se exceder
- AC: Visual regression test em 3 breakpoints (390, 768, 1280) PASS
- AC: Contraste WCAG AA mínimo (4.5:1 texto regular, 3:1 large)
- AC: Touch target ≥44x44px (mobile)
- AC: Componente listado no Storybook com states (default, hover, error, loading, disabled)
```

### Pattern D — Audit Log AC (qualquer story write sensível)
```
- AC: Tabela audit_{domínio} (append-only) recebe evento com schema {actor, action, target, payload_hash, timestamp, source_ip_hash}
- AC: Constraint NO_DELETE no banco (RLS + trigger)
- AC: Retenção mínima alinhada legal (5a LGPD para safety; 1a operacional)
- AC: Query de auditoria via endpoint admin restrito (RBAC)
- AC: Exportação CSV para DPO em <30s para janela 30d
```

### Pattern E — Accessibility AC (qualquer story user-facing)
```
- AC: Navegação keyboard completa (Tab, Shift+Tab, Enter, Esc)
- AC: aria-labels presentes em todos os interactive elements
- AC: Screen reader test (NVDA/VoiceOver) — fluxo principal sem trap
- AC: Prefers-reduced-motion respeitado em animações
- AC: Focus visible em todos os interactive (outline ≥2px contraste 3:1)
- AC: Texto escalável até 200% sem quebra de layout
```
