### Fallback se LOI não fechar 13/Jun

**Cenário A — Top candidato passou ≥40/50 mas timing impossible (defesa tese / current obligation):**
- Extend deadline para 2026-07-15 com signed letter of intent informal (não vinculante, mas sinaliza commit mutual)
- Vesting começa retroactive a 2026-06-13

**Cenário B — Nenhum candidato ≥40/50 + reference clean:**
- Stretch search 4 semanas adicionais (até 2026-07-11)
- Considerar Tier 4 (PhD candidates finishing 2026) mais agressivamente
- Considerar **interim solution híbrida**: comitê safety expandido para 5-7 advisors retainer R$1,5k/mês + 0,1% equity cada, mantém founder solo até LOI fechar Q3/2026
- **CUSTO:** Series A 2027 começa com 30-40% discount confirmado (Halle Tecco) + DPO conflito Sprint 5 NR-1 outreach exposto

**Cenário C — Top candidato recusa post-offer:**
- Voltar para candidato #2 imediatamente
- Se também recusa → cenário B (stretch 4 semanas)
