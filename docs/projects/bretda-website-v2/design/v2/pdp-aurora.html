Why this object

A single object,
uncompromised.

Aurora is built around one idea: that a game table can be the most considered piece in the room. The frame is shaped from a single run of selected hardwood, its corners eased to a soft 4 mm radius so the light travels rather than catches. The base is a continuous ribbon of polished steel — no visible fasteners, no seams to forgive.

Tournament-grade slate. Hand-stretched worsted cloth. A play surface levelled to within a fraction of a millimetre. What looks like restraint is, in fact, a hundred decisions made so that nothing distracts from the line of the table itself.
